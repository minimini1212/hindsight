## 왜 결정을 따로 적나

결정은 뒤집힌다. 뒤집힌 결정에서 **잃는 것은 결론이 아니라 근거**다. 다음 사람(6개월 뒤의 나 포함)이
*"왜 이렇게 안 했지?"* 라고 물을 때, 답이 없으면 **이미 버린 길을 다시 걷는다.**

그래서 각 파일은 이 넷을 적는다.

1. **무엇을 정했나** — 한 문장
2. **무엇을 알고 그렇게 정했나** — 🔴 반대 근거도 적는다. 「무엇을 알고도 진행했나」가 답변 가능해야 한다
3. **무엇을 버렸나** — 검토했지만 안 쓴 길과 그 이유
4. **무엇이 이걸 뒤집게 만드나** — 이 결정이 틀렸다고 판명될 조건

## 아직 안 적은 것

⬜ **결정하지 않은 것을 코드로 결정하지 않는다.** 아래는 미정이고, 코드가 먼저 답을 정하면
그건 결정이 아니라 사고다.

- 기록을 얼마나 오래 보관하나 (지금은 총량 1GB 상한만 있다)
- 에이전트가 손으로 짠 JSON을 계속 쓸지, 이진 형식으로 갈지 → v1에서 정한다
- 기록 저장소를 파일에서 DB로 옮길지 → v3에서 화면이 필요해지면
