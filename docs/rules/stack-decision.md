# 기술 선택 결정 — 자바 판, 빌드 도구

> **2026-09-10 결정.** 설계 문서는 처음에 Java 25 라고 적었다. 실제로 빌드를 돌려 보고 21 로 내렸다.

## §1 무엇을 정했나

| 무엇 | 값 |
| --- | --- |
| 바깥 모듈 | **Java 21** |
| 남의 JVM 에 들어가는 모듈 (`model`·`agent`·`agent-boot`) | **Java 17** |
| 빌드 | **Gradle 9.3** (래퍼 포함) |
| 툴체인 | `foojay-resolver-convention` **1.0.0** 이 필요한 JDK 를 직접 받아 온다 |

## §2 왜 25 가 아니라 21 인가

처음 설계는 Java 25 였다. 최신 LTS 이고 「요즘 것을 쓴다」는 신호가 되니까.

**바꾼 이유**: 25 가 이 프로젝트에 주는 것이 없다. 쓰려던 것 — 레코드, 패턴 매칭, 실드 인터페이스,
가상 스레드 — 은 **전부 21 에 있다.**

그리고 값을 치른다.

- 이 기계에는 JDK 17 하나만 있었다. 25 를 쓰면 **누구든 처음 빌드할 때 JDK 를 새로 받아야 한다**
- 국내 기업이 실제로 돌리는 건 17 과 21 이다. 이 저장소를 열어 볼 사람의 환경도 그쪽이다

⚠️ **혁신은 아껴 쓰는 자원이다.** 이 프로젝트는 바이트코드 계측과 채점 고리에 그걸 다 쓴다.
JDK 판 번호에 한 장을 더 쓸 이유가 없다.

## §3 왜 17 과 21 을 나누나

에이전트는 **관측 대상 앱과 같은 JVM 에서 돈다.** 앱이 Java 17 이면 우리도 17 이어야 한다.
실무에 17 앱이 여전히 더 많고, 에이전트는 **호환 범위가 넓을수록 쓸모가 커진다.**

🔴 이 분리가 실제로 되는지는 **컴파일된 클래스 파일의 판 번호로 확인한다.**
2026-09-10 확인: `hindsight-model` major=61(Java 17), `hindsight-core` major=65(Java 21).
설정만 해 두고 안 확인하면 조용히 하나로 합쳐진다.

⚠️ **17 로 컴파일하는 것과 17 에서 실행되는 것은 다른 일이다.**
`MethodHandles.privateLookupIn` 이나 클래스 주입 경로는 판마다 다르게 동작한다.
그래서 v1 에서 demo-app 을 **CI 에서 17·21 둘 다** 돌린다. (TODOS)

## §4 겪은 문제

### foojay 리졸버 0.9.0 은 Gradle 9.3 에서 죽는다

`IBM_SEMERU` 만 남기고 빌드가 실패한다. **1.0.0 으로 올려야 한다. 내리지 말 것.**

### `java` 가 아니라 `java-library` 여야 한다

모듈 대부분이 `hindsight-model` 의 타입을 자기 메서드 서명에 그대로 노출한다.
그런 의존성은 `api` 로 선언해야 쓰는 쪽까지 타입이 보이는데, `api` 는 `java-library` 플러그인이 준다.

### 🔴 model 에 애너테이션을 못 붙이는 것의 대가

`hindsight-model` 은 Jackson 애너테이션을 못 쓴다(그 라이브러리가 남의 JVM 으로 딸려 들어가므로).
그 결과 **파생 메서드를 `@JsonIgnore` 로 막을 수 없다.**

`Integrity.isIncomplete()` 가 자동으로 `incomplete` 필드가 되어 왕복이 깨졌다.

- ❌ 시도: 매퍼에서 getter 자동 인식 끄기 → **Jackson 은 record 접근자도 getter 로 본다.**
  전부 꺼져서 `{ }` 가 나왔다
- ⭕ 지금: **model 의 파생 메서드는 `get`·`is` 로 시작하지 않는다**
  (`hasGaps`, `windowFellShort`, `allowsAutoPullRequest`).
  규칙을 사람이 기억하는 대신 왕복 테스트가 지킨다 — 실제로 그 테스트가 이걸 잡았다

## §5 무엇이 이 결정을 뒤집게 만드나

- 21 에 없는 기능이 정말로 필요해지면 바깥 모듈만 올린다. 에이전트는 **절대 안 올린다**
- 파생 메서드가 새는 문제가 또 나면, 그때는 Jackson 대신 **직접 쓴 매핑**을 검토한다
  (에이전트 쪽은 v1 에서 어차피 그렇게 될 수 있다)
