## 2. 🔴 여기까지 오는 데 찾은 구멍 여섯

**전부 검사로는 안 보이던 것들**이다. 한 번 돌려 봐야 보인다.

| | 무엇 | 어떻게 보였나 |
| --- | --- | --- |
| ① | 503 을 「키가 틀렸다」와 똑같이 다룸 | 서버가 **「나중에 다시 하라」**는데 고리가 끝남 |
| ② | 재생 테스트가 **양쪽을 다 단언** | 패치가 붙으면 앞쪽 단언이 반드시 깨져 ㉡ 이 영영 통과 불가 |
| ③ | 전체 빌드에서 «뺀» 시험을 `--tests` 로 고름 | `No tests found` 가 **「테스트 실패」로 읽힘** |
| ④ | `gradlew.bat` 을 이름만 주고 부름 | 🔴 **세 번 다 「패치 후에도 실패」인데 한 번도 «안 돌았다»** |
| ⑤ | 준비 단계가 패치를 **즉시** 씀 | 🔴 **「패치 전」이 「패치 후」였다** |
| ⑥ | **성공**하고 나서 트리가 안 되돌아감 | ㉣ 이 다시 붙인 것을 마지막 되돌리기가 못 뗌 |

### 🔴 ④가 가장 무서웠다

세 번 시도해서 세 번 다 **「패치 후에도 재생 테스트가 실패한다」**가 나왔다.
그래서 「LLM 이 못 고치는구나」로 읽힐 뻔했다. 실은 **테스트가 한 번도 안 돌았다.**

그걸 찾아 준 것은 **바깥 명령의 출력을 파일로 남기게 한 것**이었다.

```
'gradlew.bat'은(는) 내부 또는 외부 명령, 실행할 수 있는 프로그램이 아닙니다.
```

🔴 **「테스트가 실패했다」와 「빌드를 못 돌렸다」를 안 가르면 영영 못 보는 자리다.**

### 🔴 ⑤와 ⑥은 «같은 실수의 양쪽»이었다

⑤: 준비가 패치를 즉시 써서, 네 겹이 ㉠(패치 «전»)을 잴 때 이미 패치가 있었다.
게다가 ㉠ 에서 일찍 끝나면 되돌리는 코드가 안 불려서, **다음 시도가 「이미 패치된 파일」을
「원래 내용」으로 읽었다.** 그 뒤로는 되돌려도 패치된 상태로 돌아간다.

⑥: 반대로 **성공**했을 때. ㉣ 은 되돌려 본 뒤 통과하면 패치를 **다시 붙여 둔다**
(그래야 PR 이 그 상태를 커밋한다). 그런데 되돌리기가 목록을 비워 버려서,
마지막 되돌리기가 아무것도 못 뗐다 — **사람의 작업 트리가 고쳐진 채로 남았다.**

⚠️ **실패 경로만 보고 성공 경로를 놓쳤다.** 시험으로 둘 다 못 박았다.

컴파일이 안 되는 패치도 통과해 버린다.

## 4. ⚠️ 모델을 바꿔야 했다

`.env` 의 `gemini-2.5-flash` 는 **계속 503**(과부하)이었다.
`gemini-2.0-flash` 는 서버가 **「더 이상 없다」**고 답했다(404).
**`gemini-3.6-flash`** 로만 응답이 왔다.

🔴 `.env` 는 안 건드렸다 — 환경변수로만 지정해서 쟀다. 바꾸려면 그 한 줄이다.

그리고 무료 등급 **요청 한도(429)** 에도 걸렸다. 그래서 두 가지를 더했다.

- 일시적인 것(408·429·5xx)은 **두 배씩 기다리며 세 번**까지 다시 두드린다
- 영구적인 것(401·404)은 **한 번에 끝낸다** — 404 가 1초 만에 끝나는 것으로 확인
- 🔴 다시 두드리는 것은 **예산을 안 깎는다** — 답을 못 받았으면 돈도 안 썼다
- 429 일 때 **서버가 한 말**(언제 풀리는지)을 버리지 않고 같이 적는다

## 5. ⬜ 무엇이 아직 확인 안 됐나

- 🔴 **PR 을 진짜로 올려 본 적이 없다.** `GITHUB_TOKEN` 이 없어 전부 연습이다.
  ⬜ 권한 부족 · 브랜치 이름 충돌 · 본문 길이 거절은 **부딪혀 봐야 보인다**
- 🔴 **한 번 성공한 것이다.** 같은 기록으로 두 번 돌려 둘 다 성공했지만,
  ⬜ **다른 버그 모양**(예외 · 커넥션 누수)에서도 되는지는 **모른다**
- ⬜ **확신도가 「높음」까지 간 적이 없다.** 재생 등급을 `FixRunner` 가 안 넘긴다 —
  넘기려면 재생을 «고리 안»에서 한 번 더 돌려야 하고, 그러면 206초가 더 는다
- ⬜ **비용이 0센트로 나온다.** 무료 등급 기준으로 가격을 0 으로 준 결과다.
  🔴 유료로 넘어가면 그 0 은 거짓이 되고, 그 순간 상한이 상한이 아니게 된다
- ⬜ **요청당 추가 시간 · 앱 시작 시간**은 여전히 못 쟀다 (잡음이 세 자릿수 크다)
- ⬜ **`hs` 를 기록 수백 건에서 안 봤다**
- ⬜ **3분 영상**을 안 찍었다 — 사람만 할 수 있다
